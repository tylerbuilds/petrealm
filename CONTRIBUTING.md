# Contributing

Use Node.js 22.19+ or 24.11+ on Linux or macOS. Run `npm ci`, `npm test` and `npm run build`, then try your change in the browser with `npm run dev`. In your pull request, explain what changed and how you checked it.

Keep the game local: no tracking, secrets, paid service requirements or private account captures. Use original code, copy and artwork. Put public research sources and clear limits in `docs/research/`. Follow the existing code style. Keep older saves working, or add and test a way to upgrade them.
